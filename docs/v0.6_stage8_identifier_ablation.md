# v0.6 Stage 8: identifier-routing ablation

The repository now provides `run_identifier_routing_ablation.py`. It compares
the complete local system with a version that removes only exact PMID/NCT
resolution and keeps the same database, question set, generator, ranked
retrieval fallback, and network setting.

The output records both arms, the question-set hash, the database data
version, disables both structured and exact-identifier routing in the ablation arm, and records automatic diagnostics. The ablation is an engineering test of
retrieval behavior. It is not a semantic correctness score and does not
replace source-level review.

The public 20-question holdout does not contain PubMed or NCT records, so it
cannot exercise this component. The ablation should be run on a domain corpus
that contains explicit identifiers. Private runs and any restricted source
material remain outside the public repository.
