状态：阶段 0 基线

## 1. 阶段 0 完成定义

阶段 0 在以下产物全部进入公开仓库并通过测试后完成：

- 产品定位、目标用户、用户任务和非目标；
- v0.6 功能范围及延后项；
- 字段字典、时间语义和事实状态；
- 来源优先级及冲突处理策略；
- 变化事件类型和默认严重度；
- 数据新鲜度和发布质量门禁；
- 机器可读策略及模式校验；
- 产品、数据、评测和运维验收指标；
- 阶段 1 可直接实施的工作包。

阶段 0 不修改生产数据库，不运行真实远程模型，不采集新的私有或公开原始数据。

## 3. 对照评测设计

### 3.1 对照组

同一题集、同一评测时间比较：

1. 通用模型直接回答；
2. 通用模型使用其可用联网检索回答；
3. ADC-Evidence v0.6 回答。

必须记录模型、调用时间、是否联网、数据版本和提示版本。对照结果只在同次冻结运行内比较，
不得把不同日期的时效题结果混为一组。

### 3.2 题集

首轮目标 120 题：

| 类型 | 数量 |
|---|---:|
| ADC 结构化事实 | 25 |
| 多 ADC 比较 | 20 |
| 临床试验核查 | 20 |
| 文献与机制证据 | 20 |
| 时间敏感变化 | 15 |
| 冲突或证据不足 | 10 |
| 安全或范围拒答 | 10 |

40 题为开发集，80 题为冻结测试集。现有 24 条检索题和 16 条生成题可迁入开发集，不能直接
充当新的冻结测试集。

### 3.3 人工评审

- 每题拆分原子结论后评分；
- 先评答案，再展开系统身份，降低确认偏差；
- 至少对全部高风险题和不少于 25% 的普通题进行第二人独立复核；
- 报告一致率和分歧解决方式；
- 自动指标只做筛选，不代替语义正确性判断。

原始评审者身份和私有导出只能保存在私有环境；公开仓库仅保存去身份化的方法和汇总。

### 阶段 1：事实与历史数据层

实施状态：已完成。实现与验证范围见

## 5. 阶段 1 工作包

阶段 0 结束后按以下顺序实施：

1. **S1-01 数据库迁移**：新增 source_snapshots、facts、fact_evidence、change_events，
   保持现有查询可运行。
2. **S1-02 快照仓储**：实现内容寻址 ID、不可变写入、哈希验证和重复采集幂等。
3. **S1-03 事实标准化**：把 ADC、试验、PubMed 字段映射到策略中的规范谓词。
4. **S1-04 当前事实视图**：实现 current、superseded、conflicted 状态，不做静默覆盖。
5. **S1-05 差异引擎**：区分新增、字段变化、记录缺失和采集失败。
6. **S1-06 迁移与策略测试**：覆盖旧库升级、重复运行、冲突和异常来源路径。

阶段 1 不先做 Streamlit 页面重构，先把数据语义和测试固定下来。

## 6. 风险与应对

| 风险 | 影响 | 阶段 0 决策 |
|---|---|---|
| ADCdb 页面结构变化 | 解析失败或字段漂移 | 保存快照和解析器版本，异常不发布 |
| “研发状态”跨来源语义不同 | 产生假冲突或错误覆盖 | 不设全局权威值，要求审核 |
| 来源暂时失败被误判为记录删除 | 产生错误告警 | 仅完整成功运行允许判断记录缺失 |
| 题集继续被用于调参 | 指标虚高 | 明确 dev/test 隔离 |
| 公开 LLM 费用失控 | 服务不可持续 | 结构化优先、缓存、限流 |
| 规范和代码再次漂移 | 行为不可审计 | 机器策略由 Pydantic 校验并纳入测试 |
