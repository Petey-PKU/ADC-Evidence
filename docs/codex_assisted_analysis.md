# 无 API 模型的 Codex 辅助分析协议

本项目可以完全在离线结构化路径下运行，不需要调用 `.env` 中配置的远程模型。ADC
字段、比较、临床试验字段、变化事件和拒答规则都由确定性代码执行；文献路由可以选择
离线抽取式生成器，因此不使用 API 也能完成工程验证和数据库质量评估。

Codex 可以直接参与项目分析：检查数据库结构和数据版本、运行离线评测、归纳错误模式、
起草论文表格，以及对匿名化答案进行定性复核。私有数据库应只在私有副本上提供给分析，
原始数据库、评审者身份、自由文本备注和密钥不能进入公开仓库。

当前对话中的 Codex 模型不应被默认为项目的一个可复现实验 API。若论文把 Codex 参与的
判断作为研究过程的一部分，需要保存：任务日期、模型或产品标识、完整提示词、输入输出
哈希、题集哈希、数据版本、人工复核者和分歧裁决记录，并明确标注为“Codex 辅助分析”。
这类辅助结果不能替代独立人工复核，也不能单独作为系统准确率或优越性的证据。

在不使用任何远程模型的投稿路线中，建议报告确定性系统与离线抽取式基线的结果，并由
至少两名独立复核者评定正确性、证据支持、引用对应、完整性和拒答合理性。若以后需要
模型对照，应另行固定一个可重复的模型版本和运行环境；不得把不同时间的对话结果直接
合并为同一实验组。
