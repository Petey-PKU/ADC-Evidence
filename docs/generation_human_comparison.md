# 离线基线与硅基流动生成结果人工对比

## 复核范围

2026-08-20，`domain_reviewer_1` 完成 56 条队列的单人领域复核：24 条检索问题/Gold、
16 条离线生成/拒答结果和 16 条硅基流动 `DeepSeek-V4-Flash` 结果。所有结论均与被审
内容哈希绑定，当前过期结论为 0。

下面的生成对比使用同一组 12 条可回答问题和 4 条拒答问题。它是小规模、非盲测、
单复核者工程评测，不是模型排行榜或临床性能结论。

## 人工确认的差异

### 离线基线

- `gen_pubmed_001`：机制摘录包含正确 Gold 文档，但第一行把被询问的文献识别为
  `pubmed:41321283`，预期为 `pubmed:34413126`；判定 `partial / medium / wrong_source`。
- `gen_trial_001`：正确给出 II 期试验 `NCT04879329`，但又混入另一项 III 期试验
  `NCT05911295` 的标题；判定 `partial / medium / wrong_source`。

这两个问题来自规则摘录对多个高排名文档的拼接，而不是 Gold 检索失败。

### DeepSeek-V4-Flash

- `gen_profile_005`：命中正确文档且引用合法，但只回答研发状态，遗漏靶点和 payload
  class；判定 `partial / medium / missing_key_fact`。

该问题已增加显式多字段回答清单。一次独立真实回归完整覆盖三个字段，关键事实词召回
由 0.3333 升至 1.0000；这只是单题单次回归，不代表全局模型提升。

## 关键结论

离线基线的自动关键事实词召回更高，但人工完整正确率更低，因为词面指标能奖励“包含
关键词”，却没有惩罚同时混入的错误来源。真实模型的自动词面召回较低，部分原因是
`PHASE3`/“III 期”等等价表达；人工判断后，其完整正确率更高。

因此项目不能只展示单一自动分数。更可靠的组合是：Gold 命中与引用格式负责工程门槛，
关键事实词召回负责候选筛选，领域人工复核负责判断语义支持、完整性和错误来源。

## 下一步边界

- 离线摘录保留为零费用、确定性工程基线，不把它包装成自然语言模型；
- 若继续优化离线基线，应限制多文档拼接，优先只抽取与问题实体和 Gold 研究一致的字段；
- 若继续验证多字段提示修复，应使用新 run ID 重跑或重复采样，保留旧运行和人工结论；
- 正式 benchmark 需要独立测试集和第二复核者一致性分析。
